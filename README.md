# РодКод

Многостраничный сайт семейной компании: родословные книги, поиск предков,
родословные древа и создание истории семьи.

## Что реализовано

- премиальная главная страница по пяти этапам продаж;
- отдельные SEO-страницы для 20 родословных книг;
- отдельные страницы трёх генеалогических услуг;
- каталог с фильтрами по категории и бюджету;
- бесплатная консультация с минимальной формой «имя + телефон»;
- сценарный чат-помощник с передачей разговора менеджеру;
- D1-хранилище заявок и серверная валидация;
- sitemap, robots, canonical, Open Graph, Product, FAQ и Breadcrumb schema;
- самостоятельные юридические страницы со скачиванием и печатью в PDF.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Проверка:

```bash
npm run lint
npm test
```

После изменения `db/schema.ts` сгенерируйте миграцию:

```bash
npm run db:generate
```

## Важное перед промышленным запуском

1. Заполнить реквизиты владельца/оператора данных во всех документах.
2. Проверить документы с российским юристом.
3. Подтвердить локализацию основной базы персональных данных в РФ.
4. Настроить рабочий процесс обработки новых заявок менеджером.
5. Добавить реальную фотографию основателя.
6. Публиковать отзывы и кейсы только с подтверждением и разрешением клиентов.

Текущие кейсы на главной прямо обозначены как демонстрационные сценарии.
